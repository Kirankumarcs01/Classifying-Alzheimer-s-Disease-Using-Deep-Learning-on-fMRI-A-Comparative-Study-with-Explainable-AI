# Classifying-Alzheimer-s-Disease-Using-Deep-Learning-on-fMRI-A-Comparative-Study-with-Explainable-AI
Comparative deep learning study classifying Alzheimer's Disease from resting-state fMRI. Compares BiLSTM, GCN, GAT, SVM and fusion models on 262 ADNI3 subjects (132 ROIs). Best result: SVM 71.3% / BiLSTM AUC 0.778. XAI identifies 75% neurologically validated brain regions.
